🤖 AI Intelligent Chatbot

The AI Intelligent Chatbot is an AI-powered conversational application designed to provide intelligent responses and document-based question answering. The project combines a modern React frontend with a FastAPI backend and local AI models through Ollama.

Project Overview

The application uses Llama 3.2 through Ollama for language-model based responses. It also implements Retrieval-Augmented Generation (RAG) to allow users to upload documents and ask questions based on their content.

Key Features

  • AI-powered conversational chat using Llama 3.2/Ollama.
  • React-based interactive chatbot interface.
  • FastAPI backend for API communication and application logic.
  • Persistent chat history for conversations.
  • Document upload functionality.
  • Retrieval-Augmented Generation (RAG) for document-based question answering.
  • ChromaDB-based document retrieval.
  • Nomic embeddings for document representation.
  • Chat-scoped retrieval for keeping document context associated with the relevant conversation.
  • Source citations to help identify the information used for generated answers.
  • Automated testing for important application functionality.

How It Works

  1. The user interacts with the chatbot through the React frontend.
  2. Requests are sent to the FastAPI backend.
  3. Ollama runs the Llama 3.2 model to generate responses.
  4. When documents are uploaded, their content is processed and prepared for retrieval.
  5. Nomic embeddings are used to represent document content.
  6. ChromaDB stores and retrieves relevant document chunks.
  7. The retrieved information is provided as context for the AI response.
  8. The chatbot generates an answer and provides relevant source citations.

Technologies Used

Python FastAPI React Ollama Llama 3.2 RAG ChromaDB Nomic Embeddings SQLite REST APIs

🛡️ AI-Driven Threat Detection System for Cybersecurity

The AI-Driven Threat Detection System is a machine-learning based cybersecurity application designed to identify suspicious login activities and potential security threats.

Project Overview

The system analyzes login-related security data and uses the Isolation Forest machine-learning algorithm to identify anomalous activities. An interactive Streamlit dashboard provides a visual interface for monitoring login activity, identifying suspicious behavior, and reviewing security information.

Key Features

  • Detection of suspicious login activities.
  • Machine-learning based anomaly detection.
  • Isolation Forest algorithm for identifying anomalies.
  • Data processing and analysis using Pandas.
  • Interactive Streamlit dashboard.
  • Security-related data visualization using Matplotlib.
  • MySQL integration for login data management.
  • Automated threat alerts for suspicious activities.

How It Works

  1. Login activity data is collected and prepared for analysis.
  2. Relevant security-related features are processed.
  3. The Isolation Forest algorithm analyzes the data to identify unusual login behavior.
  4. Suspicious activities are identified as potential anomalies.
  5. The Streamlit dashboard presents the results through tables, metrics, and visualizations.
  6. MySQL is used for login data management and threat-related information.

Technologies Used

Python Streamlit Scikit-learn Isolation Forest Pandas Matplotlib MySQL
